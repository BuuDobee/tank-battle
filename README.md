# 坦克大战 (Tank Battle)

经典 FC 坦克大战（Battle City）的 HTML5 复刻版，纯前端实现，打开即玩。

## 在线试玩

克隆后直接用浏览器打开 `index.html` 即可。

```
git clone https://github.com/BuuDobee/tank-battle.git
cd tank-battle
# 用浏览器打开 index.html
```

## 操作说明

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` / `W A S D` | 移动坦克 |
| `Space` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

手机端支持触屏操作。

## 游戏要素

| 地形 | 说明 |
|------|------|
| 🧱 砖墙 | 可被子弹摧毁 |
| ⬜ 钢墙 | 不可摧毁 |
| 🌊 水域 | 坦克无法通过，会沉没 |
| 🧊 冰面 | 坦克会打滑 |
| 🌲 树林 | 遮挡视野 |
| 🏠 HQ 基地 | 底部中央，被摧毁则游戏结束 |

## 关卡

共 5 个关卡，每关敌人数量和速度递增：
- 第 1 关：普通敌人 × 6
- 第 2 关：加入冰面地形
- 第 3-5 关：敌人速度更快、数量更多

## 技术栈

- HTML5 Canvas
- 原生 JavaScript（无框架）
- 单文件，约 800 行代码
